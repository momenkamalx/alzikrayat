Project:
Alzikrayat Photo Sharing Application
MVC photo sharing web app

## Technology
   Flask(python) 
   MySQL 
   HTML 
   CSS
   JS 


## how to run

1. Install [XAMPP](https://www.apachefriends.org/)
2. Start MySQL in the XAMPP Control Panel
3. Create the database and load it:
   cmd:
   mysql -u root -p -e "CREATE DATABASE alzikrayat;"
   mysql -u root -p alzikrayat < schema.sql
   
4. Install Python dependencies:
   cmd:
   pip install -r requirements.txt
   pip install bcrypt
   
5. Run the app:
   cmd:
   python run.py
   
6. Visit the ip addres shown in cmd
